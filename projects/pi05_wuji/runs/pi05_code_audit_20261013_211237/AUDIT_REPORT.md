相同留出stack轨迹的控制对照：旧端点插值达到540帧仍失败；使用实际子步位置、保持评测原有控制增益及在线重力补偿，401帧通过任务门槛。另一个同时恢复位置/增益/前馈的对照404帧通过。两次不同执行方式的单次结果不同，但不足以证明因果。追加真实命令检查发现，该stack轨迹子步与端点插值的最大差仅0.0001124rad；七条留出轨迹中除pick_place一帧最大0.01594rad外，其余也基本等于直线插值。因此需重复对照区分浮点/接触敏感性或仿真非确定性；不能将子步信息损失认定为整体低成功率根因，也不能把专家回放当作π0.5成功。证据：evidence/profile_interpolation_deviation.json。
